# The Quick Stop Coffee Shop

## About the Website

The Quick Stop is a coffee shop website created as part of my web development project.

The website provides information about the coffee shop and allows customers to view the menu and place an order.

## Website Pages

The website contains five pages:

- Home
- Menu
- About
- Order
- Contact

## Technologies Used

- HTML
- CSS
- JavaScript

## Features

- Simple navigation menu
- Coffee shop information
- Menu page
- Online order form
- Contact information
- Footer on each page
